# Token 统计桌面仪表盘重设计

## 目标

在不改变后端 API、统计口径和现有功能的前提下，将当前通用深色卡片式界面重做为具有明确辨识度的桌面数据工作台。视觉方向采用 **Night Ledger 的高级账本气质 + Signal Room 的高密度布局**：深黑底、暖金关键值、冷青运行信号、清晰的表格层级。

项目只服务桌面浏览器，不新增手机端适配。

## 设计原则

1. **钱和总量最醒目**：今日 Token、预估费用和数据源占比构成首屏核心。
2. **高密度但不拥挤**：使用细分隔线、紧凑表格和明确字号层级，减少同质化大卡片。
3. **颜色有职责**：暖金表示金额和核心指标，冷青表示运行状态，来源颜色仅用于来源识别，告警保持橙红。
4. **桌面优先**：页面最小内容宽度 1180px；不添加 viewport 或移动端媒体查询。
5. **零新依赖**：继续使用原生 HTML、CSS、JavaScript 和现有 Chart.js 文件，不引入字体或 UI 库。

## 页面结构

### 1. 顶部控制栏

- 左侧使用文字标识 `TOKEN LEDGER / 06` 和 `Token 统计`，不再使用通用机器人图标作为视觉中心。
- 右侧保留在线状态、更新时间和告警设置。
- 在线状态改为冷青信号灯；审计为警告时不会伪装成全局健康正常。

### 2. 首屏总览

- 左侧约 62%：今日总消耗、精确值悬停、预估费用、日期。
- 右侧约 38%：六个来源的占比列表和横向比例条。
- 数字使用等宽字体；标题使用衬线字体形成账本气质。

### 3. 周期指标带

- 昨天、近 7 天、本月、累计保持四列。
- 每项使用细边框分区，不再表现为四张漂浮卡片。
- Token 为主值，费用为暖金次值，来源摘要降低对比度。

### 4. 运行与洞察

- 运行审计和异常洞察组成同一工作区段。
- 审计使用三列：数据源、入库状态、口径风险。
- 洞察卡改为紧凑信号条；警告、信息和正常状态通过左边线区分。

### 5. 数据分析区

- 周期切换保留今日、近 7 天、本月、累计，并提升当前选中态。
- 按模型与按项目表格保持现有字段和分页逻辑。
- 近 30 天趋势图使用更克制的网格、细线和来源色，不使用大面积渐变填充。
- TOP 10 会话保留点击下钻；明细展开后使用内嵌账本面板，不弹新页面。

## 视觉系统

- 背景：`#080909`，表面层 `#0d0f10`，分隔线 `#272827`。
- 主文本：`#f1eee7`，次文本 `#9b9a94`。
- 核心暖金：`#e6c77a`；运行冷青：`#78dce8`；正常绿：`#8ccf9b`；告警橙：`#ef8b5d`。
- 标题、正文和数字统一使用系统字体，macOS 优先使用苹方；数字通过 `tabular-nums` 保持对齐，不再使用衬线或等宽特殊字体。
- 正文基准字号为 15px，统计表格为 16px，标签、表头、状态和辅助信息不低于 13px，保证桌面端长时间查看的可读性。
- 圆角控制在 2–8px，减少当前大面积圆角卡片感。
- 背景使用极淡水平账本线和局部径向光，不引入图片素材。

## 动效与交互

- 页面首次加载只做一次 280ms 的分段淡入。
- 表格行 hover、按钮 focus、周期切换使用 120–160ms 过渡。
- 尊重 `prefers-reduced-motion`，关闭非必要动画。
- 告警设置继续使用模态框，并补齐 `role="dialog"`、标签关联和键盘焦点样式。
- 保留现有请求竞态保护、告警日期逻辑和自动刷新。

## 用户体验优化

- 顶部增加紧凑的区段导航，可直接跳到总览、审计、明细、趋势和会话，解决桌面长页面反复滚动。
- 记住当前周期选择；刷新页面后仍停留在今日、近 7 天、本月或累计中的上次选择。
- 周期按钮同步 `aria-pressed`，在线状态使用 `aria-live`，视觉状态与辅助技术读取一致。
- 告警设置支持 `Escape` 关闭、点击遮罩关闭、打开后聚焦第一个输入、关闭后焦点回到触发按钮。
- 后台刷新失败时保留当前已渲染数据，只在更新时间区域显示错误，不清空仪表盘。
- 页面内跳转使用平滑滚动；用户选择减少动效时立即滚动且关闭装饰动画。

## 技术边界

- 保留所有现有 DOM ID 和 API 调用契约，避免改动后端。
- 主要修改 `static/index.html`、`static/styles.css`，`static/app.js` 仅调整渲染所需标记和 Chart.js 外观配置。
- 不拆分前端构建工具，不增加 npm、CSS 预处理器或组件框架。
- 不实现主题切换、移动端布局或新的统计功能。

## 验证标准

1. 所有现有 Python/Node 回归测试通过。
2. `node --check`、Python compileall、`git diff --check` 通过。
3. 桌面真实页面无空白、无错误遮罩、控制台无应用错误。
4. 今日/近 7 天/本月/累计切换正常，会话明细可打开和关闭。
5. 周期选择刷新后保持；顶部区段导航可到达对应区域。
6. 设置模态框可打开、保存、取消及使用 Escape 关闭；输入标签可被辅助技术识别，焦点可恢复。
7. 桌面视口无页面级横向滚动，表格内容不遮挡关键金额列。

## 明确不做

- 手机端和响应式布局。
- 后端统计、数据库和价格规则调整。
- 新的数据可视化类型或筛选器。
- 外部字体、图标库和前端依赖。
